## 3. 離線防掉資料第一階段

### 3.1 本階段要做到

- 場勘、施工、驗收、工作日誌輸入時自動暫存。
- 文字、選項、數值與照片暫存在手機的 IndexedDB，不只放 React 記憶體。
- 每一筆草稿使用固定 `recordId`，重新同步時更新同一筆，不新增重複資料。
- 建立本機待同步佇列（outbox），記錄：
  - 操作類型。
  - 紀錄 ID。
  - 戶別 ID。
  - 本機版本。
  - 最後修改時間。
  - 重試次數。
  - 照片待上傳狀態。
- 斷線時仍可繼續填寫，顯示「尚未同步」。
- 恢復網路後自動依序上傳照片，再同步紀錄。
- 同步成功後清除對應 outbox，但保留已儲存的本機快取供恢復。
- 同步失敗保留資料並顯示「同步失敗，點擊重試」，不可刪除草稿。
- 關閉網頁或手機重新開機後，重新進入同一戶別可恢復草稿。

### 3.2 衝突及防重複

- 每筆紀錄保留 `baseVersion`、`updatedAt`、`updatedBy`。
- Supabase 寫入使用固定紀錄 ID 作為冪等鍵，避免重送產生兩筆。
- 不同紀錄可自動合併。
- 同一筆、同一欄位被兩人修改時，不直接覆蓋：
  - 保存本機版本。
  - 下載最新雲端版本。
  - 顯示「需要選擇保留內容」。
- 照片獨立記錄上傳狀態，未完成上傳前紀錄仍顯示「照片待同步」。

## 4. 系統操作規格化

### 4.1 共用檢查卡

場勘、SPC、施工、驗收全部盡量使用同一個 `InspectionCard`：

1. 項目名稱與目前狀態。
2. 合格／不合格／待確認／不適用。
3. 需要時顯示數值及單位或選項。
4. 拍照。
5. 備註／合格依據／不合格原因與改善方式。
6. 暫存或完成。

不一次展開全部欄位；總覽只顯示按鈕卡，點入後才填詳細內容。

### 4.2 統一狀態與按鈕

- `○ 待確認`
- `✓ 合格／完成`
- `! 不合格／有異常`
- `— 不適用`
- `💾 暫存`
- `✓ 完成`
- `✏️ 修改`
- `📷 拍照`
- `📝 備註`
- `📋 查看紀錄`
- `✍️ 簽名`

同一動作在所有頁面使用相同圖示、顏色、文字及位置。

### 4.3 降低必填壓力

- 現場不知道的資料允許選「待確認／待補」。
- 只有安全判斷、完成送出及不合格原因等必要資料才強制必填。
- 草稿永遠允許儲存未完成內容。
- 完成前統一進入「最後確認」。

### 4.4 新手提示

第一次登入只顯示一個簡短提示，可關閉且不重複干擾：

`① 選案場 → ② 選戶別 → ③ 開始檢查 → ④ 拍照 → ⑤ 暫存／完成`

各頁頂部只保留一句「下一步要做什麼」，不製作長篇教學。

## 6. 應收帳款明細表（Word）

### 6.1 版型依據

參考：

- `LINE_ALBUM_0826 驗收日誌 及 帳款明細表_260826_1.jpg`
- `LINE_ALBUM_0826 驗收日誌 及 帳款明細表_260826_2.jpg`

只重製正式印刷內容，不包含手寫日期、勾號、批註、簽名筆跡或圈選內容。

### 6.2 頁面結構

- A4 直式、黑白表格、適合公司列印。
- 標題：`{案場名稱} SPC`。
- 副標題：`神銀建材 應收帳款明細表`。
- 上方欄位：送貨連絡人、送貨地點。
- 明細欄位：
  - 日期。
  - 型號。
  - 戶別。
  - 數量（坪數）。
  - 單價／元（暫時留白）。
  - 合計（暫時留白）。
- 表尾：銷貨小計、稅金、應收合計、數字字軌；金額規則尚未確定，先保留空白欄位。
- 保留主管、審核、製表及收款帳戶資訊位置；內容沒有資料時留白，不自行臆測。
- 資料超過一頁時自動分頁，每頁重複標題及表頭。

### 6.3 自動帶入資料

- 案場名稱：Project.name。
- 送貨地點：Project.address。
- 日期：優先使用施工日期；沒有施工日期時使用驗收日期。
- 型號：品牌／系列／SPC 型號／色號中已有的資料，組成可讀文字。
- 戶別：棟別＋樓層＋戶號，顯示格式沿用系統。
- 數量：驗收坪數；沒有時使用施工坪數合計，再沒有則使用預估坪數。
- 金額：本次不計算、不帶入 2,750 或照片中的任何金額。

### 6.4 預覽驗證

- 預覽列出實際匯出的所有戶別。
- 顯示總戶數與總坪數。
- 坪數缺漏的戶別標成「待補」，完成匯出前由使用者確認是否仍要匯出。
- 產生後必須做 Word 結構檢查及頁面渲染檢查；若環境缺少 LibreOffice，明確記錄只能做結構驗證。

### 7.3 自動帶入及計算

- 月份標題依預覽選擇的年月產生，不使用民國年硬編碼。
- 客戶名稱：案場名稱＋可用的工程／材料描述。
- 商品：SPC 型號＋色號。
- 戶別：棟／樓／戶。
- 坪數：驗收坪數優先，其次施工坪數合計，再其次預估坪數。
- m²：由坪數 × 3.305785 公式計算，保留兩位小數；如果現有資料已明確以 m² 儲存，先標準化後再輸出。
- 小計列使用 Excel `SUM` 公式，不寫死數字。
- 金額、進價、應付、利潤相關欄位保留空白，但保留欄位及公式位置，待公司確認計價規則後補上。
- 不輸出 `#REF!`、`#VALUE!` 或其他公式錯誤。

### 7.4 預覽與驗證

- 網頁預覽顯示月份、戶別筆數、總坪數、總 m² 及前幾筆資料。
- 可以取消或返回修改篩選條件。
- 確認後才下載 `.xlsx`。
- Excel 匯出後檢查：公式、總數、型別、日期格式、列印範圍、凍結表頭、重複表頭及所有公式錯誤。
- 每個工作表至少渲染一次做視覺檢查。
